# SyncCal — descargas

Instaladores oficiales de **SyncCal** para Android (archivo APK).

- Página de descarga con las instrucciones de instalación: https://synccalapp.app/descargar.html
- Cada versión está en la sección **Releases**, con la huella SHA-256 del archivo para comprobar que no cambió.

Este repositorio **solo contiene los instaladores**. No incluye el código de la app.
